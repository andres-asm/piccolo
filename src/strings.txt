# piccolo's UI text, in English: the ONE source of every string ID.
#
# key = English text
#
# The build turns this into enum class Str (one ID per key, in this order),
# the English table, and piccolo.pot (the template translators start from).
# Translations live in lang/<language>.po (msgctxt = the key).
#
# Keys: lowercase letters, digits and '_' (they become C++ names; never
# rename one without updating the .po files). Text: the rest of the line;
# \n is a line break, \" a quote, \\ a backslash. Keep printf-style %
# formats out of the text: numbers and names are added by the code.
