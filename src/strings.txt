# piccolo's UI text, in English: the ONE source of every string ID.
#
# key = English text
#
# The build turns this into enum class Str (one ID per key, in this order),
# the English table, and piccolo.pot (the template translators start from).
# Translations live in lang/<language>.po (msgctxt = the key).
#
# Keys: lowercase letters, digits and '_' (they become C++ names; never
# rename one without updating the .po files). Text: the rest of the line;
# \n is a line break, \" a quote, \\ a backslash. Keep printf-style %
# formats out of the text: numbers and names are added by the code.

# Settings: Sync
setting_timing = TIMING

setting_wait_for_present = WAIT FOR PRESENT
setting_wait_for_present_help = Don't start the next frame until this one is on screen (or, where the GPU can't tell, until the GPU has finished it).
setting_frame_delay = FRAME DELAY (MS)
setting_frame_delay_help = Vsync timing: wait this long before running each frame, so input is read later. Too much and frames are missed: raise it slowly.
setting_frame_delay_auto = AUTO FRAME DELAY
setting_frame_delay_auto_help = Ignores FRAME DELAY: each game starts at the longest delay the display allows and lowers it each time a frame is missed (the first 5 seconds don't count: games stall on their own while starting). After a minute of play in a row without a miss (pausing, the menu or another window start the minute over) it locks and is kept for that game. If the game later gets more demanding (a heavier scene), the locked delay may be too long: missed frames and sound cutting out; turn AUTO off or SEARCH AGAIN.
setting_catch_up = CATCH UP MISSED FRAMES
setting_catch_up_help = Vsync timing: when the system stalls and a frame comes late, run the frames it missed, so the game and its sound don't fall behind. Off: a stall slows the game for a moment and the sound may cut out.
